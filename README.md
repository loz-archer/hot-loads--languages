# Hot Loads languages

This repository contains the language files used by Hot Loads.

The non-English translations were initially generated using AI. They may contain mistakes, awkward wording, or terminology that does not fit the context of the application.

Contributions are very welcome. If you are a native speaker or spot something that could be improved, please open a pull request with your corrections. When editing a language file, preserve its existing keys, placeholders such as `{name}`, and plural forms separated by ` | `.
